	\section{Objetivos}
	Aplicar el manejo de interrupciones externas, temporización y almacenamiento persistente mediante EEPROM en un entorno de microcontroladores.  
	Los objetivos específicos son:
	\begin{itemize}
		\item Implementar un temporizador configurable en minutos y segundos.
		\item Emplear interrupciones para la gestión de eventos de usuario.
		\item Guardar y recuperar parámetros en la memoria EEPROM.
		\item Utilizar una estructura de máquina de estados (FSM) para controlar el flujo del sistema.
	\end{itemize}

	\section{Materiales y Equipos}
	\subsection{Hardware}

	\section{Metodología}
	
	\subsection{Parte A — Configuración inicial}
	\begin{enumerate}
		\item Realizar las conexiones de botones y LEDs según el diagrama de pines establecido.
		\item Asignar interrupciones externas para los botones \texttt{UP} y \texttt{DOWN}.
		\item Configurar la comunicación serial y la lectura de parámetros desde la EEPROM.
	\end{enumerate}
	
	\subsection{Parte B — Lógica de control}
	\begin{enumerate}
		\item Definir la estructura de la máquina de estados:
		\begin{itemize}
			\item \textbf{Configuración:} ajuste de minutos y segundos mediante botones.
			\item \textbf{Guardado:} almacenamiento de valores en EEPROM.
			\item \textbf{Conteo:} ejecución del temporizador decreciente.
			\item \textbf{Fin:} notificación de finalización y reinicio.
		\end{itemize}
		\item Implementar las rutinas de interrupción para los botones que alteran los valores del temporizador.
		\item Procesar las banderas de interrupción en el bucle principal para mantener la ejecución no bloqueante.
	\end{enumerate}
	
	\subsection{Parte C — Validación del sistema}
	\begin{itemize}
		\item Comprobar la escritura y lectura correcta de datos en la EEPROM.
		\item Verificar la respuesta del sistema ante pulsaciones sucesivas o rápidas.
		\item Confirmar la exactitud del conteo y el reinicio tras la finalización.
	\end{itemize}
